# A macro for HC Cargo waves 1-9

Detects spawn -> walks to camping spot -> autoclicks until wave ends -> repeat for desired number of waves

**Requirements**:
  1. Lvl 100
  2. Equipped minigun, festive rpg/m320
  3. Private server gamepass (no luring by others from behind)
  4. Installed python

**PERKS**
These perks **MUST** be equipped:
**Speed demon**, **steady hand**

Other recommended perks:
**Juggernaut, heavy hitter** (use heavy hitter if you have 3 perks)

Failure to use these perks may result in undesirable performance and death.
